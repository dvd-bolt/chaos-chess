# Chaos Chess — правила для агента

- Заметки проекта: Obsidian `1-Projects/chaos chess/` (`00 — Обзор.md`, `01 — Дизайн игры (GDD).md`). После существенного прогресса обновляй состояние, roadmap и журнал там.
- Источник правды по правилам: `docs/GDD.md`; карты и колоды: `web/src/engine/cards.js` (графика карт — `tools/cards.py`).
- Графика генерируется кодом: `cd tools && python3 -I assets.py ../web/assets ../preview && python3 -I extras.py ../web/assets ../preview && ../../runtime/pyvenv/bin/python -I style24.py ../web/assets ../preview`. Третий шаг (стиль v0.4 «Камень», нужен Pillow) перезаписывает фигуры, скины, доски, подсветку, карты, аватары (24 шт.), ману и логотип; формы фигур — `tools/style24_shapes.json`, решения по стилю — Obsidian/результаты `results/pixel_styles/РЕШЕНИЯ.md`. Эффекты, эмоции и иконки карт остаются из первых двух шагов. Ассеты руками не правим.
- Названия и образы только свои, без заимствований из чужих игр.
- Node: `../runtime/node/bin/node` (22.20, в PATH его нет). Онлайн-сервер — служба `chaos-chess` (systemd, порт 127.0.0.1:8099), сайт https://chess.138-124-126-138.sslip.io через nginx `sites-available/chaos-chess`. База `data/chaos.db`, копии `data/backups` (таймер `chaos-chess-backup`, 04:30). Секреты — `server/.env` (BOT_TOKEN, TG_APP_LINK, ADMIN_TOKEN, ADSGRAM_BLOCK_ID), не выводить и не коммитить.
- После правок движка: все тесты, фаззинг, при изменении карт — `tools/balance.mjs`. После правок сервера — `sudo systemctl restart chaos-chess` (идущие партии закроются ничьей).
- Прогресс игрока хранится в localStorage `cc_meta` и копией на сервере (players.meta). Принцип: за деньги — только косметика.
- Магазин за Stars: `server/shop.mjs` (каталог, цены), бот и оплата: `server/tgbot.mjs` (длинный опрос; включается при BOT_TOKEN). Продаётся только косметика.
- Кэш клиента (17.11.2026): сервер вставляет в index.html `<base href="/v/<версия>/">`, версия = свежайшее mtime файлов `web/` (пересчёт раз в 30 с). Картинки и шрифты под `/v/…` кэшируются на год, без версии — `no-cache` + 304. После перегенерации ассетов старые картинки в Telegram больше не залипают; рестарт для этого не нужен.
- Владелец (17.11.2026): игрок с tg_id = kv `owner_id` (задаётся через бота) при каждом входе получает всё — все карты, уровень 30, все скины/доски/титулы и все товары магазина без оплаты (`isOwner`/`ownerMeta`/`ownedFor` в server.mjs). Игрок, зашедший сначала без Telegram, привязывается к tg_id при первом входе из Telegram (db.mjs `linkTg`). Списки скинов и досок — `web/src/engine/cosmetics.js`.
- Полноэкранный Telegram (17.11.2026): tg.js ставит `--sa-top`/`--csa-top` и классы `tg`, `tg-full`; `#app` отступает на `--top`, своя кнопка «←» в Telegram скрыта (есть системная «Назад»), заголовок экрана стоит между кнопками Telegram.
- Вирусность и монетизация v0.5 (17.11.2026): приглашения и наградные титулы — `server/growth.mjs` (таблицы `referrals`, `awards`; tg id засчитывается один раз, только новые игроки, после первой партии); турниры в группах (`/tournament [4|8]`, кнопки регистрации, сетка, техпобеды) — `server/tournament.mjs` (таблица `tournaments`); сезон, пропуск (бесплатная/платная дорожки), ступени «Меценат», ступени за друзей — `web/src/engine/rewards.js` (общий для клиента и сервера); параметры запуска (`room_`, `ref_`, `pz_<день>[_c]`, `watch_`) и запасные ссылки (TG_APP_LINK → главный Mini App → бот /start → сайт) — `web/src/engine/links.js`. Донаты `donate50/150/500` повторяемые (`repeat`). Сопернику видны скин, титул и значок — сервер проверяет их по `lookFor`. Картинки для `shareMessage` — `data/share/` (живут неделю). Тесты с поддельным Bot API: `tests/growth_server.test.mjs` (`TG_API_BASE`). Проверка в Chromium: `../tools/qa_v05.mjs`. Отчёт: `results/Chaos Chess — отчёт v0.5 Друзья и сезон.md`.
